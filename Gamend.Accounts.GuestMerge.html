    Gamend.Accounts.GuestMerge (gamend_core v1.1.1360)

    Copy Markdown View Source

    A guest's progress joins the account they log in to.

    A guest (Gamend.Accounts.User.anonymous?/1: no email, no provider) who signs in to an account they already have used to lose everything they did: the session moved to the account and the guest account was deleted. Before it is deleted now, its progress is merged into the account (GamendWeb.UserAuth.log_in_user/3 calls merge/2).

    One rule throughout: the account's own data is never overwritten or deleted. The guest's is added where it fits, and what cannot be combined stays with the guest account, which nobody can reach once the session has moved, and goes with it.

    In order, each step logged and skipped on failure so a sign-in never fails because of a merge:

    1. The host (merge_user_data/2 hook) merges what it understands: its own KV keys with its own rules (counts added, histories joined). A key it is done with it deletes from the guest, so step 2 leaves it alone.
    2. KV: every guest key the account lacks moves over (Gamend.KV, so caches and subscribers follow). A key both have stays the account's.
    3. Wallets: each balance is added to the account's (Gamend.Economy.grant/4). A host that grants starting coins spends the guest's own grant first in step 1, so it is not counted twice.
    4. Inventory: quantities added (Gamend.Inventory.grant_item/4).
    5. Leaderboards: Gamend.Leaderboards.merge_user_records/2 (best kept, counters added, the account's never lowered).
    6. Quests: Gamend.Quests.merge_user_progress/2 (periods the account has not played).
    7. Activity days the account lacks; the guest's analytics events, content reports and notifications become the account's.
    8. users.metadata and users.preferences keys the account lacks.

    Sessions, push tokens, bans, lobby and party seats are not moved. Wallet and inventory grants carry idempotency keys and every other step only moves what the account lacks, so running it twice adds nothing twice.
