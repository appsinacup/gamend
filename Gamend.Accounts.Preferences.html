    Gamend.Accounts.Preferences (gamend_core v1.1.1310)

    Copy Markdown View Source

    A user's private settings (users.preferences): what only they see and change — notification choices (Gamend.Notifications.Preferences), their time zone (Gamend.Accounts.TimeZone) and the site language they last used (locale/1, for email written to them).

    Kept out of metadata on purpose: metadata is sent to friends, lobby and party members (User.serialize_brief/1), and a user's time zone or email choices are nobody else's business. Every user serializer lists its fields, and this one is in none of them.

    Writes are serialized per user (Gamend.Lock) and re-read the row, so two settings changed at once cannot lose each other.

    Some are set by the page itself (put_client/3, PUT /preferences): the site's theme, and whatever a host adds to config :gamend_core, :client_preferences (a map of key to allowed values, e.g. %{"game_sounds" => ~w(on off)}). Only those keys, with only those values, can be written that way.
