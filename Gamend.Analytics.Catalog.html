    Gamend.Analytics.Catalog behaviour (gamend_core v1.1.1361)

    Copy Markdown View Source

    What the analytics a game reports MEAN: which events and counters there are, what each is called, which group it belongs to, which of its fields are dimensions (a closed set to filter and break down by) and which are numbers (to average). The admin Analytics pages read it to group, label and offer filters; nothing is stored by it.

    A host declares its own with a module implementing this behaviour:

    config :gamend_core, :analytics_catalog, MyGame.Analytics

@impl Gamend.Analytics.Catalog
def groups, do: [%{id: "games", label: "Word games", prefixes: ["web.game."]}]

@impl Gamend.Analytics.Catalog
def events do
  [
    %{
      name: "web.game.finished",
      group: "games",
      label: "Round finished",
      dims: [game: "Game", lang: "Language"],
      measures: [score: "Score", total: "Questions"],
      rates: [{"score", "total", "Score"}]
    }
  ]
end

    Core adds its own group (Payments, payments.). A name nobody declared still shows: in the group whose prefix it starts with, else in a group of its own made of its first two segments (web.game.started → web.game), labelled with the name itself. With no host catalogue that is every name, which is the page as it was before catalogues.

    An event kind is :event (reported with Gamend.Analytics.track/3: counted, and kept as a row for an account) or :counter (counted only, Gamend.Analytics.count/3: a visitor's page, a 404, a webhook).

    tabs/0 (optional) adds the host's own pages to the Analytics tab bar: [%{id: "traffic", label: "Traffic", path: "/admin/analytics/traffic"}]. A host page draws the same bar with GamendWeb.AdminLive.AnalyticsComponents.analytics_header/1.

    overview/0 (optional) tells the Overview what this game's numbers mean (overview/0 below has the keys and the defaults):

    @impl Gamend.Analytics.Catalog
def overview do
  %{
    retention_since: ~D[2026-10-14],
    activation: %{label: "Finished a round", events: ["web.game.finished"]},
    funnel: [
      %{label: "Search visits", source: {:counter, "web.visit.ref:google"}},
      %{label: "Accounts made", source: :new_accounts},
      %{label: "Paid", source: :payers}
    ],
    trial_keys: ["pro_trial"],
    bands: %{d1: {0.08, 0.2}}
  }
end

    overview()

    @spec overview() :: overview()

    What the Overview needs to know about this game, the host's (overview/0) over the defaults:

    • retention_since — the first sign-up day whose activity is counted in full (Gamend.Analytics.record_activity/2): earlier cohorts read low and are left out of D1 / D7 / D30 and the weekly cohorts. nil: every cohort counts.
    • activation — %{label, events}: a new account is activated when it reports one of events on the day it was made. nil: no card.
    • funnel — the steps, in order (funnel_source/0). Default: accounts made, registered, paid.
    • trial_keys — the entitlement keys that are a free trial. Default none.
    • bands — per rate (:stickiness, :d1, :d7, :d30), {fair, good}; the host's replace core's one by one.

    @spec tabs() :: [tab()]
