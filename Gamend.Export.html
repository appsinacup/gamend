    Gamend.Export (gamend_core v1.1.1442)

    Copy Markdown View Source

    A host's data as files another host can start from: what only the application can copy.

    • gamend.db: a SQLite database, whole and consistent while the server runs (VACUUM INTO).
    • files.tar: what the local storage adapter holds, storage/ inside.

    Nothing else, on purpose. A Postgres database needs pg_dump of the server's major, which the database's container has and the application's image does not. Objects on S3 are already off the host. .env is a file on the host, which a running application does not have. ./rebuild.sh --export DIR (deploy/gamend-deploy) gets those and calls this for the rest. Gamend.Release.export/2 is the way in from a shell.
