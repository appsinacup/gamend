    Gamend.Groups.InviteLinks (gamend_core v1.1.1368)

    Copy Markdown View Source

    A group's invite link: an admin makes one, shares it anywhere, and whoever opens it while signed in joins the group as a member, without an invite of their own or a request to approve. It works for every group type, hidden ones too, and is a pull, like a class code: the person chooses to join, nobody is added to anything.

    One link per group. It lasts link_days (GAMEND_GROUPS_LINK_DAYS, 7 by default, 0 turns links off); making a new one replaces the old, which stops working at once, and an admin may turn it off. It also stops working when the admin who made it is no longer one, so a demoted or departed admin's link does not keep letting people in.

    Joining through it takes the same room checks and before_group_join hook as any other join (source "invite_link"), and tells the admin who made the link, as an accepted invite does.

    Public API is re-exported by Gamend.Groups.

    Summary

    Functions

    create_invite_link(admin_id, group_id)

    Make a group's link, replacing the one it had: a new token, lasting link_days from now. Admins only.

    delete_invite_link(admin_id, group_id)

    Turn a group's link off. Admins only.

    get_invite_link(group_id)

    A group's link, while it works: not expired, links on, its maker still an admin. Nil otherwise. For the group's admins to show and copy.

    get_invite_link_by_token(token)

    The working link a token opens, its group preloaded, or nil: an unknown token, an expired or replaced link, and one whose maker is no longer an admin all read the same to whoever holds it.

    join_by_invite_link(user_id, token)

    Join the group a link opens, as a member. {:error, :not_found} for a link that does not work (see get_invite_link_by_token/1), {:error, :already_member} for someone already in it, and the room checks' :full and :too_many_groups.

    link_days()

    How many days a new link lasts (link_days); 0 when links are off.

    links?()

    Whether groups may have invite links (link_days above 0).
