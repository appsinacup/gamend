    Gamend.Icons (gamend_core v1.1.1371)

    Copy Markdown View Source

    The site's own icons, which people may pick instead of uploading an image: a group's icon, an account's avatar. Every heroicon, by name (rocket-launch): heroicons.com's 24px solid set, read from the host's heroicons dependency when this compiles, the same set the website draws (GamendWeb.Icons).

    An icon is nothing but a URL, path/1 (/icons/<name>.svg), stored where an uploaded image's URL would be (a group's icon_url, a user's profile_url, a leaderboard's or a quest's icon_url). The website serves it and draws it inline; a client fetches it against the server's address like an uploaded image.
