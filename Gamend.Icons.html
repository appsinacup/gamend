    Gamend.Icons (gamend_core v1.1.1409)

    Copy Markdown View Source

    The site's own icons, by name (rocket-launch): heroicons.com's 24px solid set, read from the host's heroicons dependency when this compiles, the same set the website draws (GamendWeb.Icons).

    People pick from a few of them instead of uploading an image, for a group's icon or an account's avatar: picks/0. Any other still works where it is stored, by an API client or from before there was a list.

    An icon is nothing but a URL, path/1 (/icons/<name>.svg), stored where an uploaded image's URL would be (a group's icon_url, a user's profile_url, a leaderboard's or a quest's icon_url). The website serves it and draws it inline; a client fetches it against the server's address like an uploaded image.

    A picked icon may carry one of the site's colours, path/2 (/icons/<name>.svg?color=<color>): colors/0, the theme's own by default (primary info success warning error), each a CSS colour the website draws the icon in (color_css/1). A client reads the name from the URL's color and tints it its own way; the SVG served is the same. A host picks its own colours in Elixir:

    config :gamend_core, Gamend.Icons,
  colors: ["primary", "success", {"rose", "#e11d48"}]

    a bare name being the theme's (var(--color-<name>)), a pair any CSS colour.

    Every user has an icon: one they never picked is theirs by their id, an icon and a colour (for_id/1), the same everywhere they are shown.

    Summary

    Functions

    color(arg1)

    The colour of an icon's URL (path/2), one of colors/0, or nil.

    color?(color)

    Whether color is one of colors/0.

    color_css(color)

    The CSS colour a colour is drawn in: a theme's own name its var(--color-<name>), a pair's what it gives. Nil for none of colors/0.

    color_for(term)

    One of colors/0 for term: as good as random, the same for it every time. Nil with none.

    colors()

    The colours an icon is drawn in, by name, in order: the host's (config :gamend_core, Gamend.Icons, colors: [...]), else the theme's primary info success warning error.

    for_id(id)

    The icon a user who picked none has, by their id: one of picks/0 in one of colors/0, the same for that id every time, so it is theirs wherever they are shown and in what every API answers. Nil when there are no icons.

    name(arg1)

    The name of the icon a URL is (path/1), or nil (none, an upload). A colour on it (?color=) is no part of the name, and one the site no longer has keeps the icon (drawn in none).

    name?(name)

    Whether name is an icon's.

    names()

    Every icon's name, sorted: academic-cap, …

    path(name, color \\ nil)

    The URL of an icon by name: /icons/<name>.svg, with color when one of colors/0.

    picks()

    The icons people pick from, academic-cap, …: the same order everywhere.

    put_color(params, key)

    params with the colour picked beside an icon ("<key>_color", what <.icon_picker> sends) put on the icon's URL at key (path/2), the colour's own key gone. An upload's URL stays as it is: a colour is only an icon's. With no icon picked the colour's key stays, for the form to draw it as the one an icon picked next will have.

    random()

    One of picks/0 at random, nil when there are none.

    random_path()

    The URL of an icon at random in a colour at random (path/2), nil when there are none.
