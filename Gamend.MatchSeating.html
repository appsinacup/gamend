    Gamend.MatchSeating (gamend_core v1.1.1434)

    Copy Markdown View Source

    What a game decides for a formed match: where its players sit, and whether they are asked first. matchmaking_seat_match/1 answers with one:

    def matchmaking_seat_match(tickets) do
  case room_with_a_free_seat(tickets) do
    nil -> MatchSeating.new_lobby(max_users: 10, accept_timeout_ms: 15_000)
    lobby_id -> MatchSeating.in_lobby(lobby_id)
  end
end

    Every answer is built by a function here, so a misspelt name fails where it is written: a function the compiler does not know, or an option that raises. Core does the rest: it seats the players, checks seats and blocks, and puts the tickets back in the queue when it cannot.

    Pure, and the SDK carries a copy of it (mix gen.sdk).
