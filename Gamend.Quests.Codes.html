    Gamend.Quests.Codes (gamend_core v1.1.1431)

    Copy Markdown View Source

    Redemption codes: making them, finding them, stopping them.

    A code is a way to finish a code_only quest; the quest holds everything about what the code gives. Redeeming one is Gamend.Quests.redeem_code/2, which uses the engine's private steps. Public API is re-exported by Gamend.Quests.

    Makes one code with a chosen token. A token another code already has, even on another quest, fails on :token.

    The first few players who redeemed a code, with how many there are in the uses column for the rest. A public code can have millions.
