    Gamend.Reports.Report (gamend_core v1.1.1312)

    Copy Markdown View Source

    Ecto schema for the reports table: one report a player filed about the game — a page, a word, anything a Gamend.Reports.Kind describes.

    subject is the kind's snapshot of what was reported, taken when it was filed, so the queue still reads right after the thing itself is renamed or removed. subject_ref is the kind's short key for it, which the queue groups duplicates on. data holds the kind's extra fields (a suggested correction).
