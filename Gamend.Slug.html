    Gamend.Slug (gamend_core v1.1.1369)

    Copy Markdown View Source

    A name that is also its URL, unique per account: a group's (Gamend.Groups, <owner>/<slug>), and in a host a project's or a store account's (Forge's /projects/<owner>/<name>).

    Lowercase letters and digits, joined by single - or _, as a GitHub repository name reads once it is lowercased. Unique per account, by a unique index the changeset names.

    slugify(text, fallback)

    The nearest slug to text: lowercased, every run of anything else turned into one -, trimmed, at most 64 long, and fallback when nothing is left. "My_Game.v2" is my_game-v2.
