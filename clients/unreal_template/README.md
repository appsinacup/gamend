# Gamend for Unreal Engine

An Unreal Engine 5 plugin for [Gamend](https://gamend.org), on its C++ SDK:
`UGamendSubsystem` holds a `gamend::Client` and ticks it, the **Gamend ...**
Blueprint nodes sign in and make the common calls, `OnEvent` hears the
realtime connection, and `GetClient()` is the whole SDK from C++. HTTP and
WebSockets go through Unreal's `FHttpModule` and `FWebSocketsModule`. The
guide: https://gamend.org/docs/unreal-sdk.

This directory is generated by `clients/generate_unreal.sh` from
`clients/unreal_template/` and the C++ SDK. Edit those, not this.

## Install

Copy this `Gamend/` folder into your project's `Plugins/`, open the project,
and set the server in **Project Settings > Plugins > Gamend**. A C++ module
that calls the SDK lists `Gamend` and `GamendSDK` in its `.Build.cs`.

## What is in it

| | |
| --- | --- |
| `Source/GamendSDK` | The C++ SDK as it is (`Public/gamend`, `Private`), with nlohmann/json (`ThirdParty`), minus the curl, IXWebSocket and libdatachannel transports |
| `Source/Gamend` | `UGamendSubsystem`, the Unreal transports (`GamendTransports.cpp`), `UGamendSettings`, the async nodes (`UGamendAsyncAction`) and the JSON nodes (`UGamendJsonLibrary`) |
| `REFERENCE.md` | Every REST operation of `GetClient().api()`, by tag |

In an editor build every module is a library of its own, so the SDK's classes
are exported from `GamendSDK` (`gamend/export.hpp`): a game module can call
`gamend::Client` directly. A packaged game links one executable and needs
none of it.

## Use it

Blueprints: **Gamend Login Device** (or Login Email, Sign In, ...), then the
calls you need; bind **On Event** on the subsystem. C++:

```cpp
#include "GamendSubsystem.h"
#include "GamendSDK.h"

UGamendSubsystem* Gamend = UGamendSubsystem::Get(this);
Gamend->GetClient().api().lobbies_quick_join({{"max_users", 2}},
  [](const gamend::Response& r) {
    if (auto lobby = r.as<gamend::models::Lobby>()) { /* ... */ }
  });
```

Callbacks run on the game thread, inside the subsystem's tick. The subsystem
holds `auth().on_session_changed`, which takes one listener; bind its
`OnSessionChanged` instead.
