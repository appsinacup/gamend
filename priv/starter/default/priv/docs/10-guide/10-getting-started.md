# Getting started

Every markdown file under `priv/docs/` is a guide, served at `/docs/<name>`:
this one is `priv/docs/10-guide/10-getting-started.md`, so `/docs/getting-started`.
The numbers order the folders and files and are dropped from the address; a
folder's `_category.md` names its section of the menu.

Use guides for what your players need to know: controls, rules, how to report
a problem.
